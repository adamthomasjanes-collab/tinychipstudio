“Website by” badge v2

Chip blinks every few seconds, hops now and then, and waves on hover or keyboard focus. Animation is off for visitors who prefer reduced motion. It takes the footer’s text colour and opens tinychipstudio.com in a new tab (screen readers hear “opens in a new tab”).

New in v2: sized for the 14px floor by default (the “Website by” line is 14px, the domain 18px, Chip 30px); one size setting (--tcs-size) scales everything; a colour setting (--tcs-color); a visible keyboard focus ring; a React component; image versions redrawn at the new size.

Option 2: script + tag

Once tcs-badge.js is hosted at tinychipstudio.com/badge/:

<script src="https://www.tinychipstudio.com/badge/tcs-badge.js" defer></script>
<tcs-badge></tcs-badge>
<!-- or --> <tcs-badge size="20px" color="#f4f1e8"></tcs-badge>

Option 3: React / Vite

Copy TcsBadge.jsx into src/components/. It brings its own CSS.

import TcsBadge from './components/TcsBadge.jsx'
<TcsBadge />
<TcsBadge style={{ '--tcs-size': '20px', '--tcs-color': '#f4f1e8' }} />

Option 4: image only

For page builders that strip styles and scripts. Chip still blinks; no hover wave. Use badge-ink.svg on light footers and badge-paper.svg on dark ones, at 300×48 or larger (the files carry C2PA content credentials, so use them as-is and just set the display size), wrapped in a link.

<a href="https://www.tinychipstudio.com/" target="_blank" rel="noopener"><img src="badge-ink.svg" alt="Website by tinychipstudio.com (opens in a new tab)" width="300" height="48"></a>

Checklist when you add it

  • Set --tcs-color to the footer’s main text colour if the footer row it sits in is greyed out. The badge already lightens itself a little.
  • Keep --tcs-size at 18px or more so “Website by” stays at 14px or above.
  • Give it room: it’s about 210×37px at the default size, and wraps under the copyright line on phones.
  • Use the image version only when the snippet won’t work. The image text uses the visitor’s system font.
