The existing foundation accordions, free scorecard, process, client work and portfolio interactions remain. The review banner adds temporary height and must be resolved before publication.

**Content integrity:** repaired punctuation encoding in shared copy and a dollar-sign replacement issue in generated no-JavaScript content. Added regression coverage. Pioneer Mill destinations use `https://adamthomasjanes.com/concept/prototype/`; no links to the retired Pioneer Mill WordPress conversion remain in tested studio routes.
